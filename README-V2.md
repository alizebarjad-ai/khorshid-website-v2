# khorshid-website-v2

نسخه موازی با ظاهر جدید (شیشه‌ای روشن) از پروژه khorshid-website. پروژه اصلی دست‌نخورده است؛ این پوشه را در یک مخزن/پروژه Vercel جدا استفاده کنید.

## چه چیزی تغییر کرد
- `app/theme-v2.css` (جدید): تم جدید؛ آخرین CSS بارگذاری‌شده و تم تیره قبلی را override می‌کند.
- `app/home-client.tsx`: فقط بخش هیرو عوض شد (ویدیوی پس‌زمینه، پنل شیشه‌ای، آمار). بقیه بخش‌ها و متن‌ها دست‌نخورده است.
- `app/layout.tsx`: یک خط import برای theme-v2.css.
- رنگ‌های hard-code شده در TSX و solar-motion.css به پالت روشن تبدیل شد (طلایی → آبی #4A78B0، متن‌های روشن → #020C21).
- بک‌اند (Prisma، API فرم‌ها، پنل /admin، اخبار، آپلود رسانه) بدون تغییر است.

## اجرا
cp .env.example .env   # مقادیر DATABASE_URL و ... را برای پروژه v2 تنظیم کنید
npm install && npm run dev

## نکته مهم
برای پروژه v2 دیتابیس جداگانه بسازید یا بدانید که به همان DATABASE_URL وصل می‌شود. ویدیوی هیرو از CloudFront بارگذاری می‌شود؛ برای استقلال، آن را در public/images/v2 ذخیره و src را عوض کنید.
