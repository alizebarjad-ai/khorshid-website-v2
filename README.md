# وب‌سایت انجمن خورشید

پروژه وب‌سایت رسمی انجمن خورشید.

## فناوری

- Next.js
- TypeScript
- Tailwind CSS
- React

## توسعه محلی

```bash
npm install
npm run dev
```

سپس مرورگر را روی `http://localhost:3000` باز کنید.

## وضعیت

این مخزن در مرحله آماده‌سازی اسکلت فنی پروژه است. محتوای عمومی سایت پس از نهایی‌شدن معماری و محتوای تأییدشده انجمن به پروژه اضافه خواهد شد.
